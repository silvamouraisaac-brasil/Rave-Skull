# Rave Visuals

> An experimental terminal animation for lovers of rave visuals.

**Rave Visuals** é um projeto experimental feito em Python para quem curte a estética psicodélica, caótica e hipnótica dos visuais de rave.

O projeto transforma o terminal em uma experiência visual com mandalas, caveiras, símbolos, partículas, padrões e animações coloridas.

## Features

* Animações procedurais em tempo real
* Mandalas psicodélicas
* Caveira animada com abertura da mandíbula
* Símbolos e partículas orbitando
* Efeitos de túnel e ondas
* ASCII art preenchida com `░▒▓█`
* Cores RGB via ANSI
* 8 cenas diferentes
* Controle de FPS

## Tecnologias

* Python 3
* `math`
* `time`
* `os`
* ANSI Escape Codes

Sem bibliotecas externas.

## Como executar

```bash
python rave_visualizer.py
```

Para encerrar:

```text
Ctrl + C
```

## Conceitos utilizados

O projeto explora principalmente:

* Trigonometria
* Funções `sin()`, `cos()` e `atan2()`
* Matrizes de caracteres
* Animação baseada em tempo
* Renderização em terminal
* ANSI True Color
* Controle de FPS

## Cenas

O visualizador alterna automaticamente entre diferentes animações:

```text
Mandala
Mandala Turbo
Skull Dance
Skull Jump
Chaos Skull
Tunnel
Chaos
Final
```

## Objetivo

Não é um projeto feito para resolver um problema específico.

É um experimento para explorar programação, matemática e arte generativa através do terminal.

**Code meets rave visuals.**
